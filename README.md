# درع: نسخة عرض

نسخة عرض من موقع **درع**، أداة تطابق سياسات الأمن السيبراني في المنشأة مع ضوابط الهيئة الوطنية للأمن السيبراني (NCNICC-1:2025).

- فيها العرض التجريبي كامل على شركة وهمية (متجر نخلة الإلكتروني): الفحص، والنتائج، والفجوات، والتصحيح المقترح، والتقرير.
- رفع الملفات والتحليل يعملان في النسخة الكاملة على جهاز المنشأة فقط، لأن النموذج يعمل محليًا ونص السياسات لا يخرج من الجهاز.
