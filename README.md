# درع: نسخة عرض

نسخة عرض من موقع **درع**، أداة تطابق سياسات الأمن السيبراني في المنشأة مع ضوابط الهيئة الوطنية للأمن السيبراني (NCNICC-1:2025).

- فيها العرض التجريبي كامل على شركة وهمية (متجر نخلة الإلكتروني): الفحص، والنتائج، والفجوات، والتصحيح المقترح، والتقرير.
- رفع الملفات والتحليل يعملون في النسخة الكاملة على جهاز المنشأة فقط، لأن النموذج يعمل محليًا ونص السياسات ما يطلع من الجهاز.

**الفريق:** ناصر آل هقشه، أحمد الشهري، أسامة هروبي، ثامر عيد
**الإشراف:** أ. لمى عياش، أ. غيداء الشهري
مشروع تخرج في أكاديمية أولو.
